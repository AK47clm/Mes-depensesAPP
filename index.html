Connexion bancaire

Open Banking
Pas de connexion directe dans cette version. Une page HTML seule ne peut pas protéger les secrets OAuth ni exploiter durablement les API AISP. Pour connecter une banque, il faut un prestataire réglementé ou un statut/mandat adapté, une authentification forte, un backend sécurisé et un contrat de service.

La DSP2 autorise l’accès aux données de comptes avec le consentement explicite de l’utilisateur et impose des échanges sécurisés. Revolut dispose d’une API Open Banking pour les prestataires tiers réglementés : ce n’est pas une API personnelle librement utilisable depuis un navigateur. Le partenariat public Revolut–Tink trouvé concerne le paiement initié via Tink ; il ne prouve pas à lui seul une couverture de lecture des transactions Revolut pour votre projet. Société Générale est disponible dans des services d’agrégation existants, mais la disponibilité et la fiabilité dépendent du connecteur et de l’offre bancaire.

Les agrégateurs proposent des offres professionnelles, parfois une possibilité d’opérer comme agent sous leur agrément. Le contrat, le contrôle d’éligibilité, la conformité, le traitement des données et l’intégration serveur restent à prévoir. Les fournisseurs consultés publient des tarifs sur devis ou demandent de les contacter : « plusieurs milliers d’euros » peut servir d’hypothèse budgétaire initiale, mais aucun tarif universel ni coût par compte n’est confirmé publiquement. Vérifiez une offre écrite pour les banques, volumes et durées concernés.

Alternative proche : saisie quotidienne ici, ou export CSV depuis SG/Revolut puis import local. L’import reconnaît les colonnes courantes Date, Libellé/Description, Débit/Crédit ou Amount. Une app bancaire d’agrégation grand public comme Bankin’ peut aussi agréger certaines banques sans développer votre propre backend ; ce serait une autre application, pas une synchronisation vers Ledger.
